# PriceTracker
This is my first official project.


# Project Goal


The primary goal of this project is to develop a mobile application that runs entirely on the user's device. The application will send requests directly to the target website, retrieve the required data, and present the information to the user in a clear and accessible way.

One of the initial ideas for this project is to retrieve and display information such as the prices of the US dollar, gold, and other relevant assets and commodities.

In addition to developing the application, this project serves as a practical learning experience for exploring and working with a Python library for building the application's frontend.
